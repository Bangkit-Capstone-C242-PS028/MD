
The technology behind Derma Scan :

firstly, we use Kotlin programming language. 

secondly, Architecture using MVVM with Repository Pattern.

thirdly, Data Persistence using Room Database.

fourthly, UI Framework using Jetpack Compose and XML

fifthly, Networking using Retrofit for handles API interactions seamlessly.

sixthly, Hilt for simplifies dependency injection.

Lastly, we use firebase for authentication
